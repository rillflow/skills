# ideation

必要な結果と現在の手段を分け、実行できる解決策や別のアイデアを探すスキルです。個人の発想、問題の捉え直し、会議、共有や返信に使えます。本文と参照資料は日本語です。

TRIZを知っている必要はありません。普段の言葉で相談すると、案、その案が働く理由、使える条件、次に試せることを返します。

| 場面 | 動作 |
|---|---|
| 短いアイデアの依頼 | 迅速モードで見方を変え、仕組みが異なる少数の方向を示します。 |
| 制約がぶつかる、同じ対処を繰り返す、深い検討を指定する | 深考モードで問題を分析し、広い範囲から解法を探して制約と失敗条件を確認します。 |
| 共有や返信 | 相手が判断・行動できる文面に組み直します。確認済みの答えに発想を無理に追加しません。 |

## インストールと使い方

```bash
npx skills add rillflow/skills --skill ideation
```

手動で配置する場合は、`references/`と`scripts/`を含む`skills/ideation/`全体を、使用するエージェントのスキルフォルダにコピーするかリンクします。

- 「毎週行うこの作業を減らしたいです。別の進め方を短く提案してください。」
- 「速度を上げると正確さが下がります。両方を改善できるか、深く検討してください。」
- 「この内容を共有したいので、読む人が何を判断するかから組み直してください。」

モードは依頼から判断します。利用者の深さ・時間・分量の指定を優先します。

## 深考の範囲

問題分析、40原理・76標準の全項目の適用検討、ARIZの9部、システムの発展、科学効果と他分野の検索、解法の検証を扱います。全項目を解法に使うわけではなく、適用外も理由を確かめます。工学モデルと一般業務への類推を分けます。

原典の閲覧にはネットワークが必要です。エージェントは、Python 3.10以降で資料を取得する補助ツールか、直接のウェブ閲覧を使います。独立した検討者を使えない、必要な資料や事実が足りない場合は、その限界を結果の判断に関わる形で伝えます。手順の完了は、案の有効性や実物試験の成功を保証しません。

## 構成

- [SKILL.md](SKILL.md): 適用場面、迅速・深考、返す内容
- [references/deep.md](references/deep.md): 深考の実行手順
- [references/triz-map.md](references/triz-map.md): 道具と原典の対応
- [references/sources.md](references/sources.md): 原典の取得・閲覧と科学効果の検索
- [references/review-record.md](references/review-record.md): 作業記録と欠落検査
- [references/evidence.md](references/evidence.md): 研究上の根拠と効果の限界
- `scripts/`: 原典を読む補助と、作業記録の構造検査

公開するのは実行指針・出典索引・補助ツールです。原文のキャッシュはリポジトリ外に保存します。科学効果データベース全体を収録したものではありません。
