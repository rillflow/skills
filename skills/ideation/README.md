# ideation

必要な結果と現在の手段を分け、問題を別の位置や条件で解けないかを検討します。個人での発想、問題の捉え直し、会議のアイデア出し、共有や返信に使えます。本文と参照資料は日本語です。

| 場面 | 動作 |
|---|---|
| 短いアイデアの依頼 | 現在の見方を変え、動作の仕組みが異なる少数の方向を示します。 |
| 制約がぶつかる、または深い検討が必要な問題 | 問題を捉え直し、案、反例、現実の条件を比べます。 |
| 物理・技術システムの発明問題 | 条件に合う場合は、TRIZの矛盾分析、分離、資源活用と工学的な深掘り手順を参照します。 |

依頼の複雑さと指定された深さに応じて検討範囲を決めます。一般的な悩みに工学分類を無理に当てはめません。

## インストール

```bash
npx skills add rillflow/skills --skill ideation
```

手動で配置する場合は、`references/`を含む`skills/ideation/`全体を、使用するエージェントのスキルフォルダにコピーするかリンクします。

## 使用例

- 「毎週行うこの作業を減らしたいです。今の方法以外の進め方を探してください。」
- 「速度を上げると正確さが下がります。両方を改善できるか、深く検討してください。」
- 「この内容を共有したいので、読む人が何を判断するかから組み直してください。」
