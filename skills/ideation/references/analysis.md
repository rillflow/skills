# 分析モード：問題の構造と矛盾を固定する

問題の構造、原因、矛盾を事実で固定し、分離と役割の移転から候補を出します。使う道具は下の一覧に固定し、実行ごとに増減しません。40原理・76標準・ARIZ・科学効果の照合と外部検索は行いません。分析の記録は下の形式で残し、深考モードはその記録を引き継いで全範囲へ進みます。

分析の記録を深考の記録として扱いません。記録と返す内容に、深考を行っていないことと、深考へ進む必要の判断を書きます。

## 使う道具

[道具の全体像](triz-map.md)のうち、次の11個を使います。各道具を使用、適用外、未確認のいずれかで記録します。適用外には現在の問題との不一致を、未確認には不足した事実を書きます。

| ID | 得るもの |
|---|---|
| problem-definition | 必要な結果、現在の手段、観測した事実、維持する機能、変えられない条件 |
| function-analysis | 要素と担い手、有益・有害・不足・過剰な作用 |
| cause-effect-analysis | 原因と結果の連鎖、制御できる原因 |
| flow-analysis | 物質・エネルギー・情報の流れと、滞留・損失・迂回。流れを変えると消える問題 |
| cost-analysis | 各要素の費用と改善余地。金額や工数がなければ未確認 |
| system-operator | 部分・全体・上位系と過去・現在・未来。問題を移すと解法が変わる境界 |
| ideality-resources | 理想的な結果と、すでにある資源 |
| contradictions | 要求上・技術的・物理的な矛盾。改善と悪化の因果と、同じ性質の反対状態が事実で確認できているか |
| separation | 時間・場所・条件・全体と部分で分けて両立させる案 |
| trimming | 要素や手順を除き、役割を別の要素へ移す案 |
| secondary-effects | 候補が生む害と、別の人や工程へ移る負担 |

物理的な対象がない問題では、要素・作用・流れを業務の担い手・処理・手順に読み替えます。読み替えたことを記録に書き、正式な工学モデルとして扱いません。

## 手順

1. 問題を固定する。必要な結果、現在の手段、観測した事実、維持する機能、変えられない条件を分けて書く。仮定には、それを変えるとどの判断が変わるかを添える。
2. 構造と原因を調べる。要素と作用、原因の連鎖、流れ、費用、上位系と時間軸から、制御できる原因と、問題を移せる境界を得る。
3. 矛盾を書き、分ける。一方を良くすると他方が悪くなる関係を、事実で確認できているものと仮説に分ける。両立できる分け方があれば案にする。
4. 資源と役割の移転を探す。すでにある要素・情報・時間・成果物で必要な働きを満たす案、要素や手順を除いて役割を移す案を出す。
5. 候補をそろえる。候補ごとに、仕組み、維持する条件、失敗する条件、別の人や工程へ移る負担、最小の判別試験を書く。既存の方法と小さな改良案も比較に残す。
6. 深考の要否を判断して返す。候補が出ない、または物理的な対象と作用があって解法カタログが候補を生みうる場合は、深考を勧めて止まる。利用者が判別試験を行って候補が成立しなかった場合も同じ。深考に入るのは利用者が続けると決めたとき。どれにも当たらなければ分析で終える。

## 記録

作業用ディレクトリにMarkdownで残します。見出しは次の順に固定します。

```markdown
# 分析記録 <日付>
## 問題
## 道具の判定（11個。使用 / 適用外 / 未確認と、得たもの）
## 矛盾と分離
## 資源と役割の移転
## 候補（仕組み / 維持する条件 / 失敗する条件 / 移る負担 / 判別試験）
## 未確認
## 深考の要否
```

利用者への回答は、依頼への答えから書きます。候補の仕組み、選ぶ理由、使える条件、次にできる行動を問題そのものの言葉で説明し、道具のIDや矛盾の分類を前提にしません。
