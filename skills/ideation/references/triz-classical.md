# 工学問題のTRIZ深掘り

物理的な対象・作用と成立条件を実際に説明できる発明問題で読みます。一般業務に物性名を付けてこの経路を実行しません。必要なモデルと事実がなければ、観測と問題の捉え直しへ戻ります。

問題モデルの矛盾表現は、[両立しない条件を実際の条件として書く](triz.md#両立しない条件を実際の条件として書く)に従います。物理的矛盾を主張するときは、同じ対象・性質の反対状態と、それぞれが必要な理由を結果に残します。成り立つ矛盾が見つからなくても、機能、資源、作用の変化で探索できます。深い検討の形を整えるために矛盾を作りません。

## 正式な矛盾モデルの独立検証

技術的・物理的矛盾として確定したモデルを回答の根拠に使う場合は、解法の生成と分けて、そのモデルだけを検証します。同じ生成過程の自己確認で検証を代用しません。独立した検討エージェントを使えるなら、利用者の原文、確認した事実、矛盾の文、以下の基準だけを渡します。好む解法や合格という結論は渡しません。

- 同じ対象・性質に反対状態を求めているか。異なる作用・要求をまとめていないか。
- 両方の状態が必要な根拠は、原文または確認した物理関係にあるか。一方の要求を新たに作っていないか。
- 技術的矛盾の改善・悪化関係は、観測または確認した原理で裏付けられるか。未確認の因果を確定していないか。
- 矛盾を言い換える、または仮説へ下げると、どの解法の根拠が変わるか。

検討結果は[原典の定義](https://altshuller.ru/world/eng/triz6.asp)と与えられた条件に従って最終判断します。検討者が合格と判断しただけでは採用しません。成り立たない分類は修正または削除し、その分類に頼った推奨も再検討します。独立検証ができなければ、正式な分類を未検証モデルとして残し、機能、資源、試験で裏付けられる候補だけを条件付きで示します。この手順は正式な矛盾モデルを使う工学的な深掘りに限り、一般の深考や迅速モードには適用しません。

## 40原理と矛盾行列

技術的矛盾の改善・悪化項目を標準工学パラメータへ対応させた理由を説明します。複数の対応があり得るなら、不確実さを保ちます。[MATRIZ行列の説明](https://wiki.matriz.org/docs/triz/problem-solving-tools-5890/contradictions/engineering-contradiction-5995/contradiction-matrix-6026/)と、そこからつながる行列を確認してから原理候補を得ます。確認していないセルや番号を記憶から作りません。

縦は改善、横は悪化です。逆方向のセルを同じとは見なしません。セル内の原理の順序は優先順位ではありません。空のセルも解決不能を意味しません。対応づけが無理なら、直接の分離、機能、資源の探索へ戻ります。

[40原理の原文](https://www.altshuller.ru/world/eng/technique1.asp)は、分割、分離、事前作用、動的変化のように、解法を変換する発想の手掛かりです。一つを選んだら、実際に何をどう変えるかと維持条件を説明します。原理名を付けただけで問題を解いたとは見なしません。

## 物質・場モデルと76標準

作用する物質、対象物質、両者の間の物理的な場をモデルとして書きます。不足した作用、有害な作用、検出・測定の問題のどれかを確かめます。該当要素が実際の対象に対応しなければ、76標準の番号を選びません。

[Altshullerの76標準全文](https://www.altshuller.ru/triz/standards.asp)には、次の五系統があります。

| 問題と探索の方向 | 見る系統 |
|---|---|
| 不足または有害な相互作用の構成・除去 | 物質・場系の構成と破壊 |
| 現在の作用の制御・性能発展 | 物質・場系の発展 |
| 上位系または微視的水準への移動 | システム水準の変換 |
| 検出または測定 | 検出・測定問題 |
| 使う物質、場、資源と標準の適用条件 | 標準適用を助ける方法 |

問題モデルと利用可能な資源を決めた後、関連原典の個別適用条件を読んで選びます。制限条件を落としません。候補を強められるか、不要な物質・場を取り除けるか、得た原理を別の作用に使えるかを検討します。標準の全文、公式、例をこのファイルに複製せず、具体的な番号を使うときは原典を確認します。

## 小人モデルと科学的効果

物理的矛盾で変わる部分を小さな行為者の集団として描き、ぶつかる行動を衝突しない行動へ変えてみます。その図が求める動き、結合、分離などを、実際の物理効果や技術手段へ戻します。擬人化した話だけで終えません。[ARIZ第4部](https://www.altshuller.ru/triz/ariz85v-4.asp)、[Altshullerの解説](https://www.altshuller.ru/triz/triz36.asp)。

新しい科学的効果が必要なら、信頼できる分野資料で成立条件を確かめます。ある現象が存在することと、現在の材料、温度、寸法、繰り返し条件で安全に動くという判断を分けます。確認していない物性、精度、性能値を作りません。

## 全体ARIZの経路

[公式ARIZ-85V原文](https://altshuller.ru/triz/ariz85v.asp)の該当手順を読み、実行します。英語資料のARIZ-85C表記とロシア語版を分けて、出典を残します。以下は構造の要約であり、原典の詳細条件を代替しません。

| 部 | 行う判断 |
|---|---|
| 1 | 技術システム、矛盾、有益な作用を絞り、問題モデルを選びます。[問題モデル表](https://www.altshuller.ru/triz/ariz85v-t1.asp)と実際の対象を比べます。 |
| 2 | 衝突が生じる領域、時間、物質と場の資源を確認します。 |
| 3 | 理想最終結果と、巨視的・微視的な物理的矛盾を表します。 |
| 4 | 既存・派生資源とモデルを広げます。 |
| 5 | 標準解、類似問題、物理的矛盾の変換、科学的効果を検討します。[変換表](https://www.altshuller.ru/triz/ariz85v-t2.asp)の先行条件と理想結果を確認します。 |
| 6 | 抽象的な物理解を技術解へ移します。不十分なら問題または上位系の定義を再検討します。 |
| 7 | 解消した矛盾、実際の動作・制御・反復利用、導入時の新しい問題を確認します。新規性は先行事例と比べ、特許性を断定しません。 |
| 8 | 上位系の変更、別用途や問題への転用可能性を検討します。 |
| 9 | 実際の解決過程と使った方法を比べ、新しい方法を一般化する前に別事例で検証します。 |

最初の候補が浮かんでも、後の技術化と検証を省きません。確認資料がなく進められない場合は、その境界と次の観測を明記し、完了したとは主張しません。同じ根拠で同じ失敗を繰り返しません。全体ARIZを選ばない一般の深考では、上の九部すべてを行う必要はありません。
