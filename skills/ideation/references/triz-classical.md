# 공학 문제의 TRIZ 심화

물리적 대상·작용과 성립 조건을 실제로 설명할 수 있는 발명 문제에서 읽는다. 일반 업무에 물성 이름을 붙여 이 경로를 실행하지 않는다. 필요한 모델과 사실이 없다면 관측·문제 재정의로 돌아간다.

문제 모델의 모순 표현은 [상충의 성립 조건](triz.md#상충을-실제-조건으로-쓰기)을 따른다. 물리적 모순을 주장할 때는 같은 대상·성질의 상반 상태와 각각 필요한 이유를 결과에 남긴다. 성립하는 모순을 찾지 못했어도 기능·자원·작용 변화로 탐색할 수 있으며, 심화 검토의 형식을 갖추려고 모순을 만들지 않는다.

## 정식 모순 모델의 별도 검증

기술적·물리적 모순으로 확정한 모델을 답변의 근거로 쓴다면, 해법 생성과 분리해 그 모델만 검증한다. 같은 생성 과정의 자기확인으로 검증을 대신하지 않는다. 독립 검토 에이전트를 사용할 수 있으면 사용자 원문·확인한 사실·모순 문장과 아래 기준만 전달한다. 선호하는 해법이나 합격 결론은 넘기지 않는다.

- 같은 대상·성질에 반대 상태를 요구한 것인가. 서로 다른 작용·요구를 묶지 않았는가.
- 양쪽 상태가 필요하다는 근거가 원문 또는 확인한 물리 관계에 있는가. 한쪽 요구를 새로 만들어내지 않았는가.
- 기술적 모순의 개선·악화 관계가 관측 또는 확인한 원리로 뒷받침되는가. 미확인 인과를 확정하지 않았는가.
- 모순을 다시 표현하거나 가설로 낮추면 어떤 해법 근거가 달라지는가.

검토 결과는 [원전 정의](https://altshuller.ru/world/eng/triz6.asp)와 주어진 조건으로 최종 판단한다. 검토자 합격만으로 채택하지 않는다. 성립하지 않는 분류는 고치거나 제거하고, 그 분류에 기대던 추천도 함께 재검토한다. 독립 검증을 할 수 없다면 정식 분류를 미검증 모델로 남기고, 기능·자원·시험으로 뒷받침되는 후보만 조건부로 제시한다. 이 절차는 정식 모순 모델을 쓰는 공학 심화에 한정하며 일반 고찰·빠른 모드에는 적용하지 않는다.

## 40원리와 모순행렬

기술적 모순의 개선·악화 항목을 표준 공학 파라미터에 대응시킨 이유를 설명한다. 여러 대응이 가능하면 불확실성을 유지한다. [MATRIZ 행렬 설명](https://wiki.matriz.org/docs/triz/problem-solving-tools-5890/contradictions/engineering-contradiction-5995/contradiction-matrix-6026/)과 연결된 행렬을 확인한 뒤 원리 후보를 얻는다. 확인하지 않은 셀·번호를 기억으로 만들어내지 않는다.

세로는 개선, 가로는 악화다. 역방향 셀은 같다고 볼 수 없고, 셀 안 원리의 순서는 선호 순위가 아니다. 빈 셀도 해결 불능을 뜻하지 않는다. 매핑이 무리하면 직접적인 분리·기능·자원 탐색으로 돌아간다.

[40원리 원문](https://www.altshuller.ru/world/eng/technique1.asp)은 분할·분리·사전 작용·동적 변화처럼 해법을 변환하는 발상 단서다. 하나를 선택했다면 실제로 무엇을 어떻게 바꾸는지와 유지 조건을 설명한다. 원리 이름을 붙인 것만으로 문제를 해결했다고 보지 않는다.

## 물질-장 모델과 76표준

작용하는 물질, 대상 물질, 둘 사이의 물리적 장을 모델로 적는다. 부족한 작용, 해로운 작용, 검출·측정 문제 중 무엇인지 확인한다. 해당 요소가 실제 대상과 대응하지 않으면 76표준 번호를 선택하지 않는다.

[알트슐러의 76표준 전문](https://www.altshuller.ru/triz/standards.asp)은 다음 다섯 계열을 담는다.

| 문제와 탐색 방향 | 살펴볼 계열 |
|---|---|
| 부족하거나 해로운 상호작용의 구성·제거 | 물질-장 체계의 구성과 파괴 |
| 현재 작용의 제어·성능 발전 | 물질-장 체계의 발전 |
| 상위 체계 또는 미시 수준으로 이동 | 체계 수준 전환 |
| 검출 또는 측정 | 검출·측정 문제 |
| 사용할 물질·장·자원과 표준 적용 조건 | 표준 적용을 돕는 방법 |

문제 모델과 가용 자원을 정한 뒤 관련 원문의 개별 적용 조건을 읽고 선택한다. 제한 조건을 빠뜨리지 않는다. 후보를 강화할 수 있는지, 불필요한 물질·장을 제거할 수 있는지, 얻은 원리를 다른 작용에 쓸 수 있는지 검토한다. 표준 전문·공식·예제를 이 파일에 복제하지 않으며, 구체 번호를 사용할 때는 원문을 확인한다.

## 작은사람모델과 과학 효과

물리 모순의 변하는 부분을 작은 행위자들의 집단으로 그려, 충돌하는 행동을 충돌 없는 행동으로 바꿔 본다. 그 그림이 요구하는 움직임·결합·분리 등을 실제 물리 효과나 기술 수단으로 되돌린다. 의인화된 이야기만으로 끝내지 않는다. [ARIZ 4부](https://www.altshuller.ru/triz/ariz85v-4.asp), [알트슐러의 해설](https://www.altshuller.ru/triz/triz36.asp).

새 과학 효과가 필요하면 신뢰할 수 있는 분야 자료에서 성립 조건을 확인한다. 어떤 현상이 있다는 사실과 현재 재료·온도·치수·반복 조건에서 안전하게 작동한다는 판단을 구별한다. 확인되지 않은 물성·정밀도·성능 수치를 만들지 않는다.

## 전체 ARIZ 경로

[공식 ARIZ-85V 원문](https://altshuller.ru/triz/ariz85v.asp)의 해당 단계를 읽고 실행한다. 영어 자료의 ARIZ-85C 표기와 러시아어 판본을 구별해 출처를 남긴다. 아래는 구조 요약이며 원문의 상세 조건을 대신하지 않는다.

| 부 | 수행할 판단 |
|---|---|
| 1 | 기술 시스템·모순·유익 작용을 좁혀 문제 모델을 선택한다. [문제 모델 표](https://www.altshuller.ru/triz/ariz85v-t1.asp)와 실제 대상을 대조한다 |
| 2 | 충돌이 생기는 영역·시간·물질과 장의 자원을 확인한다 |
| 3 | 이상적 최종 결과와 거시·미시의 물리 모순을 표현한다 |
| 4 | 기존·파생 자원과 모델을 확장한다 |
| 5 | 표준해·유사 문제·물리 모순 변환·과학 효과를 검토한다. [변환 표](https://www.altshuller.ru/triz/ariz85v-t2.asp)의 선행 조건과 이상적 결과를 확인한다 |
| 6 | 추상적 물리 답을 기술 해법으로 옮긴다. 불충분하면 문제 또는 상위 체계의 정의를 재검토한다 |
| 7 | 해소한 모순, 실제 동작·제어·반복 사용, 도입 시 새 문제를 확인한다. 새로움은 선행 사례와 대조하며 특허성을 단정하지 않는다 |
| 8 | 상위 체계 변경, 다른 용도와 문제에 대한 전용 가능성을 검토한다 |
| 9 | 실제 해결 과정과 사용한 방법을 비교하고, 새 방법을 일반화하기 전에 별도 사례에서 검증한다 |

첫 후보가 떠올라도 뒤의 기술화·검증을 생략하지 않는다. 확인할 자료가 없어 진행할 수 없다면 그 경계와 다음 관측을 명시하며 완료했다고 주장하지 않는다. 같은 근거와 같은 실패를 순환하지 않는다. 전체 ARIZ를 선택하지 않은 일반 고찰은 위 아홉 부를 모두 수행할 필요가 없다.
