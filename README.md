# Skills

아이디어와 문제 해결에 사용하는 개인 에이전트 스킬입니다. 스킬마다 `skills/<이름>/SKILL.md`와 필요한 참고 자료를 함께 둡니다.

## 설치

```bash
npx skills add rillflow/skills --skill ideation
```

수동으로 설치할 때는 `skills/ideation/` 디렉터리 전체를 사용하는 에이전트의 스킬 경로에 복사하거나 연결합니다. `references/`도 함께 있어야 심화 절차를 읽을 수 있습니다.

## ideation

원하는 결과와 현재 수단을 구분하고, 문제를 다른 위치나 조건에서 풀 수 있는지 살펴봅니다. 개인 발상, 문제 재정의, 회의 아이디어, 공유·회신에 사용할 수 있습니다. 본문과 참고 자료는 한국어입니다.

| 상황 | 동작 |
|---|---|
| 짧은 아이디어 요청 | 현재 관점을 바꿔 보고, 작동 방식이 다른 소수의 방향을 제시합니다. |
| 제약이 충돌하거나 깊은 검토가 필요한 문제 | 문제를 다시 정의하고, 대안·반례·현실 조건을 비교합니다. |
| 물리·기술 시스템의 발명 문제 | 조건이 맞을 때 TRIZ의 모순 분석·분리·자원 활용과 공학 심화 절차를 참조합니다. |

요청의 복잡성과 지정한 깊이에 따라 검토 범위를 고릅니다. 일반적인 고민에 공학 분류를 억지로 적용하지 않습니다.

### 사용 예

- “매주 하는 이 작업을 줄이고 싶어요. 지금 방식 말고 다른 접근을 찾아주세요.”
- “속도를 높이면 정확도가 떨어져요. 둘을 같이 개선할 수 있는지 깊게 검토해주세요.”
- “이 내용을 공유하려는데, 읽는 사람이 무엇을 판단해야 하는지부터 다시 잡아주세요.”

## 구성

```text
skills/
└── ideation/
    ├── SKILL.md
    └── references/
        ├── deep.md
        ├── triz.md
        ├── triz-classical.md
        └── evidence.md
```

TRIZ 원전 링크, 연구에서 확인된 범위, 스킬 자체의 효과를 검증할 때 구분할 기준은 [근거와 한계](skills/ideation/references/evidence.md)에 정리했습니다.
