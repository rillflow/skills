# 試験用の依頼：個人の学習資料

技術記事、動画、PDFを毎週20件くらい保存しますが、後で使うときに見つからず、同じ内容をまた検索しています。資料をもっと整理する以外の案も含めて深く考えてください。アプリを並べるより、明日からどう使い方を変えるかを知りたいです。

試験用の入力条件:
- 保存先はブラウザのブックマーク、ローカルのPDF、メモアプリです。約1,000件あり、同じ資料の重複もあります。
- ファイル名やタイトルを覚えていないことが多いです。「何に使えると思ったか」は保存時には分かっています。
- 毎週まとめてタグを付ける運用は2週間で止まりました。保存時に長文メモを書くのも続きません。
- 新しい有料サービスや、全件の手作業での移行は避けたいです。既存の検索と短いメモなら使えます。
- 資料をすべて読破することが目標ではなく、今取り組んでいることに使える情報を見つけ、同じ調査を繰り返さないことが目標です。
