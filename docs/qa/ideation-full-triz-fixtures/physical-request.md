# 試験用の依頼：撮影用の背景板

卓上で小物を撮影するときの背景板が、撮影中に前後へ倒れます。構造から深く検討し、仕組みの違う2〜3案と、まず試す案を教えてください。工作を始められる程度に具体的に知りたいです。

試験用の入力条件:
- 板は高さ60cm、幅40cm、厚さ約1mm、質量300gの均一な樹脂板です。現在は垂直に立てています。
- 現在の支持具は質量100gで、板の下端を挟み、机上の前後8cmの範囲で接地します。重心は板の真下です。
- 室内の水平な机で使います。横方向より前後方向に倒れることが多く、撮影物の位置を直す手が板の高さ30cm付近に軽く当たる場面で起きます。加わる力は未測定です。
- 板の見える前面に支えを出せません。机への接着・穴あけ・クランプ固定もできません。
- 支持具が占める机の奥行きは合計20cmまで、増やす質量は100gまでです。電源やモーターは使いません。
- 毎回片付けるので、取り外し・組み立てが簡単で、平たく運べる形が必要です。新しい板を買うより、今の板を活かしたいです。
