# ideation深考モードのQA

この検証は、手順を実行できるか、案が入力条件に合うか、回答を読んで行動できるかを調べます。実機での有効性や、他の発想方法に対する性能優位を測る試験ではありません。

## ドラフト作成時

- スキル名・説明・相対リンク: 通過。
- 原典からの40原理・76標準の境界、下位条件、script/style除去: fixtureと公開原典で確認。
- 原典キャッシュ: 103文書、40原理、76標準、ARIZの9部を取得。内容はリポジトリに含めない。
- 回答の初回実行: コミット`289218851e2e86689972cdf84c43637456bddeae`を固定し、`gpt-5.6-terra/high`で実施。

## 実行試験の基準

| 対象 | 確認すること |
|---|---|
| 工学問題 | 実際の対象・作用と原典の条件を照合し、制約に合う候補と判別試験を示す |
| 一般業務 | 工学モデルを捏造せず、機能・情報・役割の類推と正式適用を分ける |
| 迅速な依頼 | 指定分量で使える案を返し、長い原典調査や一覧表を始めない |
| 情報不足 | 不足した事実を絞り、架空の装置・原因・完了を作らない |
| 回答の使いやすさ | TRIZの知識なしに、案の違い・成立条件・次の行動が分かる |

静的な構造検査、独立した内容判定、実物試験の結果を分けて記録する。

## 初回実行の結果

| ケース | 判定 | 実際に確認したこと |
|---|---|---|
| 撮影用の背景板 | 要修正 | 三案と試験を返したが、系全体の前方転倒、総奥行き、追加質量の上限を十分に検証していなかった。原理・標準の対応にも誤りがあった |
| 個人の学習資料 | 要修正 | 回答は利用条件に合うが、原理の題名を確認しただけで本文を読んだと記録し、一部の未実行手法も使用済みにした。構造検査は通過しても意味検証は不合格 |
| 読書会の進め方 | 通過 | 依頼どおり日本語3行で、追加道具を必要としない進め方を提示。方法論の解説を付けなかった |
| 名前も症状もない装置 | 要修正 | 必要な事実を尋ね、空の未完了記録を作った。ただし対象不明のまま停止操作を付け足した |

初回の構造検査は、一般業務で終了コード0、工学・情報不足で終了コード2だった。番号の充足だけでは、原文を読んだか、解法が成立するかを判断できなかった。

修正では、本文の実読とプログラムによる読込み、道具の内訳、原典から候補への具体的な変換、系全体の作用、全要素を含む制約を確認する手順を補った。独立判定でも見落としがあったため、生成側・検討側の主張を実際の記録と計算へ戻して確認した。再実行の結果は追記する。
